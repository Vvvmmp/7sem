**Разработка простейшего JSON-RPC-сервиса**

1. Разработайте приложение-сервер (платформа – ASP.NET CORE Web API) **JSONRPCServer,** реализующий JSON RPC – интерфейс.

1. **JSONRPCServer:**  реализует вызов следующих удаленных процедур. Процедуры поддерживают позиционную и именованную передачу параметров

|  |  |
| --- | --- |
| Сигнатура | Результат |
| double SUM (double x, double y) | SUM = x + y |
| double SUB (double x, double y) | SUB = x - y |
| double MUL (double x, double y) | MUL = x \* y |
| double DIV (double x, double y) | DIV = x / y  если y = 0, генерируется ответ с ошибкой |
| int FACT(int x) | FACT = x! (факториал)  если ответ превышает размерность int - генерируется ответ с ошибкой |

1. **JSONRPCServer:** реализует пакетную обработку процедур.

1. Продемонстрировать работу сервиса с помощью клиента, разработанного на языке GO.
