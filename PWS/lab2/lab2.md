**gRPC-сервис**

**Задание 1.**

1. Разработайте приложение-сервер (платформа – ASP.NET CORE) **gRPCServer01,** реализующий gRPC – интерфейс.
2. **gRPCServer:**  реализует вызов следующих удаленных процедур.

|  |  |
| --- | --- |
| Сигнатура | Результат |
| double SUM (double x, double y) | SUM = x + y |
| double SUB (double x, double y) | SUB = x - y |
| double MUL (double x, double y) | MUL = x \* y |
| double DIV (double x, double y) | DIV = x / y  если y = 0, генерируется исключение |
| int FACT(int x) | FACT = x! (факториал)  если ответ превышает размерность int - генерируется исключение |

1. Разработайте консольное C#-приложение **gRPCClient01**, вызывающее все удаленные процедуры и обрабатывающее исключения.

**Задание 2.**

1. Разработайте аналогичный **gRPCServer01** приложение-сервер (платформа – Node.JS) **gRPCServer02,** реализующий gRPC – интерфейс.
2. Разработайте GO-приложение **gRPCClient02**, вызывающее все удаленные процедуры и обрабатывающее исключения.

**Задание 3.**

1. Продемонстрируйте работоспособность клиента **gRPCClient02** с сервером **gRPCServer01.**
2. Продемонстрируйте работоспособность клиента **gRPCClient01** с сервером **gRPCServer02.**
