**Разработка простейшего REST-сервиса с сохранением состояния на стороне сервера и клиента**

**Задание 1**

1. Разработайте ASP.NET CORE Web API-приложение **WS01-01**, обладающий следующими свойствами.
2. **WS01-01** предназначен для обработки GET, PUT, POST, DELETE HTTP-запросов к ресурсу /stack.
3. На **GET**-запрос **WS01-01** возвращает JSON-сообщение, содержащее значение **RESULT**. Первоначальное значение **RESULT** = 0 (целочисленный нуль).
4. Для хранения данных **WS01-01** поддерживает стек (на стороне сервера) в **рамках одной сессии.** Первоначально стек является пустым.
5. **POST**-запрос позволяет изменить значение **RESULT** на значение заданное в теле запроса значение **RESULT** в формате JSON.
6. **PUT**-запрос позволяет выполнить PUSH-операцию для стека поддерживаемого **WS01-01** в **рамках сессии**. Добавляемое целочисленное значение пересылается query-параметром с именем **ADD**.
7. **DELETE**-запрос выполняет POP-операцию для стека.
8. В общем случае значение **RESULT** формируется как сумма текущего значения **RESULТ** и верхнего элемента стека.
9. Конечная реализация **WS01-01** должна быть оформлена как **Self-contained/Single-File** для OS Linux и упакована в Docker-контейнер.
10. Продемонстрируйте работоспособность приложения **WS01-01**.

**Задание 2**

1. Разработайте сервер, реализующий API Gateway для двух контейнеризированных экземпляров **WS01-01.**
2. API Gateway должен балансировать запросы по алгоритму Sticky Session.
3. Продемонстрируйте работу web-системы: 2 **WS01-01** + API Gateway (Sticky Session).

**Задание 3**

1. Разработайте ASP.NET CORE Web API-приложение **WS01-02**, функционально совпадающего с **WS01-01,** но поддерживающего стек на стороне клиента в **cookie**. Выполните развертывание **WS01-02** поаналогии с **WS01-01.**
2. Продемонстрируйте работоспособность приложения **WS01-02**.

**Задание 4**

1. Разработайте сервер, реализующий API Gateway для двух контейнеризированных экземпляров **WS01-02.**
2. API Gateway должен балансировать запросы по алгоритму Round Robin.
3. Продемонстрируйте работу web-системы: 2 **WS01-02** + API Gateway (Round Robin).
