## **Лабораторная работа № 10**

## **Загрузка данных из внешних источников**

**Цель:** освоить механизмы импорта данных в 1С из файлов (Excel, XML/JSON).

**Теоретические сведения**

При автоматизации учёта часто возникает необходимость загрузить данные из внешних источников: файлы Excel (.xls, .xlsx), текстовые файлы CSV, XML-файлы, JSON-файлы, обычные текстовые файлы (TXT), внешние базы данных (через ODBC/ADO), веб-сервисы (HTTP-запросы).

Любая загрузка данных из внешнего источника выполняется по следующей схеме:

* выбор источника;
* открытие и чтение;
* парсинг (разбор): данные извлекаются из структуры файла (ячейки Excel, строки CSV, теги XML, свойства JSON);
* валидация: проверяется корректность данных (не пустые обязательные поля, соответствие типам).
* поиск существующих объектов: в базе 1С проверяется, нет ли уже записи с таким кодом или наименованием;
* создание или обновление записи;
* фиксация результата: формируется протокол загрузки (что добавлено, обновлено, пропущено, с ошибками).
* обработка ошибок.

Некоторые объекты платформы для работы с файлами:

|  |  |  |
| --- | --- | --- |
| Объект | Назначение | Поддерживаемые форматы |
| ЧтениеExcel | Чтение файлов Excel | .xlsx |
| ЧтениеТекста | Чтение текстовых файлов | CSV, TXT, JSON (как текст) |
| ЗаписьТекста | Запись текстовых файлов | CSV, TXT, JSON |
| ЧтениеXML | Построчный разбор XML | .xml |
| ЧтениеJSON | Разбор JSON-данных | .json, строки JSON |

Учитывайте, что для старых версий файлов .xls нужно использовать COM-объект Excel.Application, который требует установленного Excel. Объект ЧтениеExcel работает только с форматом .xlsx (Microsoft Office 2007 и новее).

**Ход работы**

<u>Задание 1. Импорт из Excel</u>

1. Создайте файл .xlsx с номенклатурой предприятия следующего вида:

|  |  |  |  |
| --- | --- | --- | --- |
| Код | Наименование | Единица измерения | Цена |
| Т-001 | Ноутбук Lenovo | шт | 45 000 |
| Т-002 | Мышь компьютерная | шт | 1 200 |
| Т-003 | Клавиатура | шт | 2 500 |

2. Создайте внешнюю обработку в конфигураторе: Файл → Создать → Внешняя обработка.

* Имя: ЗагрузкаНоменклатурыИзExcel.
* Добавьте реквизит: ИмяФайла (тип Строка, длина 200).
* Добавьте команду ВыполнитьЗагрузку.

2. Алгоритм загрузки

* Открыть Excel-файл с помощью объекта ЧтениеExcel.
* Прочитать использованную область на первом листе.
* Пропустить заголовок (первую строку).
* Для каждой строки:
  + Извлечь код, наименование, единицу измерения, цену.
  + Проверить, что код не пустой.
  + Найти единицу измерения в справочнике «Единицы измерения»; если не найдена — создать новую.
  + Проверить существование номенклатуры с таким кодом:
    - Если не существует — создать новый элемент.
    - Если существует — обновить наименование, единицу измерения и цену.
  + Зафиксировать результат в протоколе (добавлен / обновлён / ошибка).

3. Выполните протоколирование процесса:

* протокол выводится в табличный документ на форме;
* колонки: «Код», «Наименование», «Статус» (Добавлен / Обновлён / Ошибка);

4. Добавьте обработку ошибок:

* если файл не найден – вывести сообщение;
* если файл имеет неверный формат – перехватить исключение и показать понятное описание.

*Фрагмент кода для пояснения:*

|  |
| --- |
| // Открытие файла  Чтение = Новый ЧтениеExcel;  Чтение.ОткрытьФайл(ИмяФайла);  Лист = Чтение.Листы[0];  Область = Лист.ИспользованнаяОбласть;  // Цикл по строкам (начиная со второй)  Для НомерСтроки = 2 По Область.Высота Цикл  Код = СокрЛП(Область[НомерСтроки-1, 0].Текст);  Если Код = "" Тогда Продолжить; КонецЕсли;    // Поиск существующего элемента  Сущ = Справочники.Номенклатура.НайтиПоКоду(Код);  Если Сущ = Справочники.Номенклатура.ПустаяСсылка() Тогда  // Создание нового  Новый = Справочники.Номенклатура.СоздатьЭлемент();  Новый.Код = Код;  // ... заполнение реквизитов  Новый.Записать();  Иначе  // Обновление существующего  Сущ.Наименование = Наименование;  Сущ.Записать();  КонецЕсли;  КонецЦикла; |

5. Убедитесь, что присутствует результат выполнения:

* справочник «Номенклатура» пополнен или обновлён;
* пользователь видит протокол с количеством обработанных строк.

Арбат, д.10</ЮрАдрес>  </Контрагент>  </Контрагенты> |

2. Открыть файл через ЧтениеXML.

3. Перебирать узлы, отслеживая теги <Контрагент>.

* при обнаружении начала элемента «Контрагент» прочитать внутренние теги (Код, Наименование, ИНН, КПП);
* после получения всех реквизитов одного контрагента – записать его в справочник «Контрагенты».

*Фрагмент кода для пояснения:*

|  |
| --- |

4. Особенности реализации:

* Если контрагент с таким кодом уже существует – обновить его реквизиты.
* Если ИНН и КПП не указаны в XML – оставить пустыми.
* Вести протокол загрузки с указанием статуса (добавлен / обновлён / пропущен).
