## Ответы на вопросы

**1. Назовите директории, поддерживаемые всеми платформами?**
Temporary, Application Support, Application Documents, Application Cache, Downloads.

**2. Назовите директории, поддерживаемые только на Android?**
External Storage, External Cache Directories, External Storage Directories.

**3. Назовите используемые библиотеки в рамках лабораторной работы?**
- `sqflite` — база данных SQLite;
- `path_provider` — пути к директориям;
- `dart:io` — `File`, `Directory`, `Platform`;
- `dart:isolate` — изоляты;
- `dart:convert` — JSON.

**4. SqlLite? Преимущества и недостатки?**
SQLite — встроенная реляционная база данных: вся база хранится в одном файле на устройстве, сервер не нужен.
- **Преимущества:**
  - работает офлайн и быстро;
  - поддерживает полноценный SQL (`WHERE`, `ORDER BY`, `JOIN`, индексы);
  - есть транзакции;
  - лёгкая, работает на всех мобильных платформах.
- **Недостатки:**
  - мало типов: нет bool и даты, поэтому они хранятся как 0/1 и строка;
  - слабо подходит для одновременной записи из многих потоков;
  - нет синхронизации с сервером;
  - объекты в строки таблицы нужно преобразовывать вручную;
  - при изменении структуры таблицы нужны миграции.

**5. Какие библиотеки используются для доступа к файловой системе? Можно ли обойтись без path_provider?**
- **Чем работать с файлами.** Читать и записывать файлы позволяет `dart:io` (`File`, `Directory`). `path_provider` только сообщает, где находятся системные директории: на каждой платформе пути разные.
- **Можно ли без `path_provider`.** Можно, но неудобно:
  - прописать пути вручную — ненадёжно, они отличаются на разных ОС и устройствах;
  - получить их через свой MethodChannel из нативного кода — по сути написать `path_provider` заново.

**6. Какие библиотеки используются для работы с изолятами? Встроены ли они в Dart?**
- `dart:isolate` (`Isolate.run`, `Isolate.spawn`, `ReceivePort`, `SendPort`) встроена в Dart.
- Функция `compute()` из `package:flutter/foundation.dart` встроена во Flutter.

Сторонние пакеты не нужны.

**7. Зачем нужны изоляты? Что произойдёт при тяжёлой операции в main isolate?**
- **Зачем.** Изоляты позволяют выполнять тяжёлую работу параллельно, в отдельном потоке со своей памятью.
- **Что будет в main isolate.** Главный изолят и выполняет код, и рисует интерфейс. Если нагрузить его тяжёлой операцией:
  - кадры перестают отрисовываться, интерфейс зависает или дёргается;
  - нажатия не обрабатываются;
  - на Android система может показать «Приложение не отвечает» (ANR).

**8. Чем compute() отличается от Isolate.spawn()? Когда что использовать?**
- **`compute()` и `Isolate.run()`** — для разовой задачи. Они:
  - создают изолят, выполняют функцию и возвращают результат через `Future`;
  - сами закрывают изолят.

  Подходят для задач вида «посчитать или прочитать один раз», как у нас запись и чтение файла.
- **`Isolate.spawn()`** — для долгоживущего изолята:
  - связь через `ReceivePort`/`SendPort` настраивается вручную, сообщения можно отправлять много раз в обе стороны;
  - закрывать изолят нужно самому.

  Подходит для постоянной фоновой работы.

**9. Какие данные можно передавать между изолятами? Какие нельзя?**
- **Можно:**
  - `null`, `bool`, `int`, `double`, `String`;
  - `List`, `Map`, `Set` из таких значений;
  - типизированные массивы, `TransferableTypedData`, `SendPort`;
  - при `Isolate.run`/`spawn` — также обычные объекты Dart, включая свои классы.

  Объекты при передаче копируются.
- **Нельзя:**
  - `ReceivePort`;
  - сокеты и открытые файлы;
  - `Pointer` из FFI и объекты с нативными ресурсами;
  - виджеты, `BuildContext`, `State`.

**10. Как производилась обработка ошибок в зависимости от платформы?**
- **Как ловится ошибка.** Каждая директория получается в отдельном `try`. Если на текущей платформе директории нет, `path_provider` выбрасывает `UnsupportedError`:
  - на iOS — для External-директорий;
  - на Android — для Application Library.
- **Что выводится.** Ошибка ловится через `on UnsupportedError`, на экран выводится текущая платформа (`Platform.operatingSystem`) и список всех платформ, где директории нет.
- **Остальные ошибки** ловятся через `catch (e)` и выводятся текстом.
