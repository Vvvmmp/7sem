**Лабораторная № 10 BLoC**

**Задание:** Создать приложение, используя архитектурный паттерн BLoC, взяв за основу лабораторную работу №9 (Provider). Все взаимодействия с состоянием должны быть реализованы через BLoC.

**Рекомендуется использовать библиотеки:**

* <https://pub.dev/packages/bloc>.
* <https://pub.dev/packages/flutter_bloc>

Использование Cubit вместо Block также недопустимо.

1. Взять приложение из лабораторной работы №9 (Provider).
2. Заменить всё управление глобальным/разделяемым состоянием на BLoC.
3. Обязательно использовать:

* минимум один класс, наследующий Bloc<Event, State>;
* явные классы Event и State (иммутабельные, желательно с Equatable или freezed);
* BlocProvider или MultiBlocProvider в main.dart;
* BlocBuilder минимум в двух местах;
* BlocListener для side effects (навигация, снекбары, диалоги);
* context.read<Bloc>() для отправки событий (без перерисовки).

1. Не использовать setState для данных, которые уже находятся в BLoC.
2. Продемонстрировать асинхронную загрузку: состояния loading / success / error.
3. Не использовать устаревший mapEventToState — только обработчики on<Event>.
4. Не создавать BLoC внутри метода build().
